# Visualizer, Tools, And Testing

The primary visual inspection tools are the native visualizer and browser visualizer. Both are backed by the same `sim` visualizer pipeline.

For current visualizer behavior, see [](tools/visualizer.md). For CI and test commands, see [](testing.md) and [](development/ci.md).

The visualizer includes pages for motion, mount state, calibration, sensors, diagnostics, and road events. Road-event support includes point events, segment events, filters, map overlays, hover trigger plots, and Events-page plots.
